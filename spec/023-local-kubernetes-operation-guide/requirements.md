# 023 本地 Kubernetes 部署操作手册

## 背景

022 需求已经完成检测运行面的 Kubernetes 部署实现，但当前说明只包含少量命令，无法指导第一次接触 Docker Desktop 和 Kubernetes 的开发者独立完成部署、验证、更新和排障。

## 目标

提供一份可直接照着执行的中文操作手册，使开发者能够理解每个步骤的目的，并能根据预期结果判断部署是否成功。

## 需求

1. 说明本地部署包含的组件、调用链路和未启用的组件。
2. 说明 Docker Desktop、Kubernetes、Docker CLI 和 kubectl 的环境准备方法。
3. 详细说明项目编译、镜像构建、Secret 创建和 Kubernetes 资源部署过程。
4. 说明一键部署脚本的参数、内部动作和成功标志。
5. 说明如何检查 Pod、Deployment、Service、EndpointSlice 和 PVC。
6. 说明如何生成 HMAC 签名并调用同步文本检测接口。
7. 说明如何验证 Dubbo RPC、MySQL Flyway 迁移和 Redis 违规样本缓存。
8. 说明代码更新后的重新构建、滚动发布和回滚方法。
9. 说明常见异常的定位顺序和处理方法。
10. 区分暂停服务、删除工作负载和彻底清理数据三类操作。

## 验收标准

- 操作者只阅读本需求文档即可完成首次部署。
- 每个关键步骤都包含操作目的、执行命令和预期结果。
- 所有命令与当前 `content-risk` 命名空间、镜像名称和端口保持一致。
- 删除 PVC 或命名空间等数据破坏性操作必须有明确警告。
