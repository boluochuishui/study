# 文档设计

## 读者定位

本文档面向具备 Java 和 Spring Boot 基础、但对 Docker Desktop 与 Kubernetes 操作不熟悉的开发者。因此先解释概念和成功标志，再给出命令，不假设读者已经掌握 Pod、Service、PVC 等资源。

## 内容结构

操作手册按以下顺序组织：

1. 认识部署拓扑和目录文件。
2. 检查本机环境。
3. 执行首次一键部署。
4. 检查所有资源状态。
5. 调用真实检测接口。
6. 验证数据库、缓存和 RPC 链路。
7. 更新镜像并滚动发布。
8. 查看日志并处理常见故障。
9. 暂停、恢复或删除环境。

## 编写约定

- 命令默认在项目根目录、Windows PowerShell 中执行。
- 每一步同时描述“为什么执行”和“成功后看到什么”。
- 默认本地凭证仅用于开发环境，不作为生产配置示例。
- 涉及数据删除的命令不放入普通部署流程，并突出数据丢失风险。
