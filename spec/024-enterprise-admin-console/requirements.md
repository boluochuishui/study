# 024 企业级风控管理台前端

## 背景

项目已经具备多租户 RBAC、配置管理、SpEL 规则管理和国际化管理接口，需要建立独立前端工程承载日常配置、发布和运维操作。

## 需求

1. 前端作为独立工程构建和发布，不嵌入 Java Jar。
2. 使用 Vue 3、TypeScript、Vite、Vue Router、Pinia、Vue I18n 和 Element Plus。
3. 提供登录、权限路由和多租户身份展示。
4. 提供工作台、规则管理、配置管理、用户权限和日志查询页面。
5. 对接现有 admin-service 接口，并提供可切换的本地 Mock 数据源。
6. 建立统一请求、错误处理、类型模型和环境变量规范。
7. 提供 ESLint、Prettier、类型检查、单元测试和生产构建脚本。
8. 提供 Docker 多阶段构建和 Nginx 运行配置。
9. 支持中文、英文切换和桌面、移动端响应式布局。
10. 界面符合高频运营管理场景，重视扫描、筛选、发布和审计效率。

## 非目标

- 本期不新增后端统计和日志查询接口。
- 本期不实现拖拽式责任链编辑器。
- 本期不直接操作 Kubernetes API。
