# 验证计划

## 当前结果

本阶段仅完成基础设计文档，不修改生产代码，因此不执行新增自动化测试。

## 后续功能验证

- 精确路径、单层通配和多层通配能够正确匹配。
- 同一路径的不同 HTTP Method 能够选择不同规则。
- 多条规则命中时严格按照优先级选择。
- 同优先级重叠规则在发布前被拒绝。
- 未匹配规则、未知模式和缺失 Provider 时默认拒绝。
- `ANONYMOUS` 只能通过显式规则启用。
- Provider 鉴权失败后不会回退到其他模式。
- 新快照校验失败时继续使用上一有效版本。
- 配置源不可用时能够恢复最后有效快照。
- 多实例最终使用相同版本和 checksum。
- 回滚后所有实例切换到新生成的回滚版本。
- 日志和错误响应不包含凭证、Token 或完整签名。

## 安全验证

- 路径规范化后无法通过重复斜杠、编码字符或路径穿越绕过规则。
- 查询参数不会影响 URL 规则选择。
- 管理接口和引导规则不能被远端配置扩大匿名访问范围。
- 管理台无权限用户不能发布或回滚鉴权配置。
- 所有发布和回滚操作均产生完整审计记录。
