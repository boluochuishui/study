# 验证记录

## 自动化验证

- Maven 编译通过。
- 全量单元测试通过。
- 验证合法 HMAC 签名可生成认证主体。
- 验证请求体变化会导致签名失败。
- 验证同一 nonce 重复提交会被拒绝。
- 验证 Method 与 URL 联合匹配，未匹配请求保持默认拒绝。
- 使用真实随机端口验证 Filter 验签、请求体重复读取及 Controller 完整执行。

## 配置验证

- `V3__seed_auth_config_snapshot.sql` 使用 `INSERT IGNORE` 初始化首个数据库快照，不覆盖管理台后续维护的数据。
- 数据库不可用、配置缺失或新快照非法时保留当前有效快照。
- 初始引导快照只开放精确健康检查路径，检测接口必须使用签名。

## 后续风险

- 当前 nonce 存储为单实例内存实现，多实例部署前需要接入 Redis。
- 当前凭证通过环境变量提供，数据库密文或 STS 凭证源尚未实现。
- 管理台发布前还需补充同优先级路径冲突检测和 checksum 验证。
- 管理台阶段还需验证配置发布权限、审计、回滚和多实例版本一致性。
