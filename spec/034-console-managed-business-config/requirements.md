# 需求 034：管理台维护六张业务配置表

## 目标

为需求 033 的 `detect_app`、`detect_scene`、`detect_rule`、`media_library`、`media_asset`、`media_asset_library` 提供管理台设置页面，支持租户内列表、新建、编辑、启停。

## 约束

- 沿用现有 `CONFIG_READ` / `CONFIG_WRITE` 权限，不让浏览器提交租户 ID 或审计人 ID。
- SQL 保存在 `config-data` 的 Mapper XML，接口、数据访问与前端页面分层。
- 写入检查必填、枚举、同租户关联和内容类型匹配；使用 `version` 乐观锁。
- 凭证仅保存 `env:` 或 `secret:` 引用；媒资只保存摘要和元信息，不保存样本正文。
- 文件、文本可在浏览器本地计算 SHA-256，样本不会经管理台接口上传。
- 本需求只实现配置管理，检测服务尚未读取这些新表。

## 验收

- 管理台可依次创建 App、场景、媒资库、媒资、关联、规则，并编辑其可变字段。
- 其他租户的数据不可见、不可引用；无权限用户无法读取或写入。
- 版本过期返回冲突；关联类型不匹配或同步 LLM 配置被拒绝。
- 中英文界面可切换，六张表的设置操作均可从侧栏访问。
