# 012 音视文图拆包与异步执行需求

## 背景

音频、视频、文本、图片后续将拆分为独立微服务，当前单体项目需要先形成清晰的模态边界。异步接口需要使用 `CompletableFuture` 与受管线程池完成本地执行。

## 需求

- 文本、图片、音频、视频分别归属独立软件包。
- 每种模态提供统一检测执行接口的实现。
- 应用层通过路由器选择执行器，不直接依赖责任链名称。
- 同步接口继续只支持文本和图片。
- 异步接口支持文本、图片、音频和视频，并立即返回任务编号。
- 异步任务通过 `CompletableFuture` 和 `detect-async` 线程池执行。
- 检测结果通过现有结果发布器发布，保留后续 MQ 扩展能力。
- 服务重启时允许内存任务丢失，不提供任务持久化和自动重试。
