# 需求说明

## 背景

当前 baseSdk 中只有偏业务语义的 `BizLogEvent` 和 `BizLogRecorder`，责任链执行日志也直接依赖业务日志模型。随着系统后续拆分为多个微服务，日志模块需要具备更强的基础扩展能力，可以支撑接口日志、debug 日志、三方调用日志、责任链日志等不同类型的日志。

## 目标

- 日志模块沉淀为 baseSdk 的通用能力。
- 支持通过日志空间区分不同业务域或存储域。
- 支持通过日志类型区分接口、debug、三方、责任链、业务等日志。
- 责任链日志迁移到通用日志模型。
- 保留业务日志门面，避免后续业务代码直接绑定底层日志实现。

## 非目标

- 本需求不接入真实日志平台、Kafka、ELK、Loki 或 ClickHouse。
- 本需求不实现日志采样、脱敏、异步批量写入。
- 本需求不改变现有检测接口协议。
