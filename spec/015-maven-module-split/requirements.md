# 015 需求

将现有单体 Maven 工程拆为可复用的基础 SDK、配置数据模块和可运行的检测服务，为后续独立管理台及 RPC 微服务拆分建立模块边界。

## 验收标准

- 根工程统一管理依赖版本、质量插件和子模块构建顺序。
- `base-sdk` 提供责任链、日志、线程池、字符常量及定时热加载通用能力，不依赖检测业务。
- `config-data` 提供 MyBatis 配置数据模型、服务及 SQL 迁移文件。
- `detect-service` 保留当前 HTTP 鉴权、音视文图检测和消息队列业务，生成唯一可执行 Jar。
- 原有接口、配置、测试和 CI 质量门禁继续可用；Docker 构建指向新的 Jar。
- 不创建空的管理台应用，不改变现有业务行为。
