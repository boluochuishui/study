# 设计

浏览器提交检测类型、执行模式、样本和语种/地区；不提交密钥或选择目标 URL。管理台通过当前登录身份获取租户，从配置 SDK 读取该类型启用的测试配置。服务端配置 `admin.online-test.credentials.<tenantCode>` 绑定该租户允许使用的 App ID 和密钥。两者 App ID 不一致即拒绝请求。

管理台按检测入口 HMAC-SHA256 协议对**实际发送的 JSON 字节**签名，固定向 `/api/detect/sync` 或 `/api/detect/async` 发送。调用成功后回传检测入口响应；无论上游成功/失败，记录成功响应摘要或失败状态。MySQL 表 `admin_online_test_record` 仅留租户、操作者、类型、模式、配置标识、样本数、任务号、状态、结果 JSON、耗时和时间。列表最多返回最近 100 条。

当前异步检测结果由结果 MQ 返回，管理台没有最终结果查询通道，故记录只显示受理响应，不推断最终结论。后续可通过结果消费侧按任务号关联记录，但不在本需求中引入检测任务持久化。
