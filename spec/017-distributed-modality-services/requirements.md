# 017 需求

将统一 HTTP 接入入口与音、视、文、图检测执行拆为独立服务。入口只负责系统鉴权、请求校验、任务编号、RPC 路由和故障开放；每个模态服务拥有自己的责任链及异步任务 Topic。

## 验收标准

- 提取不依赖具体实现的 RPC/消息契约模块。
- 文本、图片服务提供同步检测和异步提交；音频、视频服务只提供异步提交。
- 接入服务不包含检测执行器、检测节点、异步线程池或 MQ 消费者。
- 同步 RPC 失败明确返回降级 PASS；异步未成功入队不得返回普通 ACCEPTED。
- Kafka 使用 `taskId` 作为消息 Key，每个模态拥有独立任务 Topic 和 Consumer Group，结果发送到统一结果 Topic。
- 四个模态服务可以独立启动、构建 Jar 和 Docker 镜像。
- 使用 Dubbo Triple 作为 RPC 协议，支持本地直连并预留 Nacos 注册中心配置。
