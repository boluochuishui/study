# 018 验证

## 自动化测试

- 验证按优先级执行、停用规则过滤、首条命中和全部命中。
- 验证根对象、变量和扩展属性的不可变性。
- 验证重复标识、空字段、超长表达式和非法语法在编译阶段失败。
- 验证类型引用、构造器、Bean 引用和方法调用在编译阶段被拒绝。
- 验证非 Boolean 结果在失败即停模式抛出异常，在跳过错误模式记录错误并继续。
