# 018 通用 SpEL 规则表达式模块需求

## 背景

音视文图检测需要把频繁变化的阈值和判定条件从代码中分离。规则后续由管理台写入数据库，并通过通用热加载框架生成内存快照，因此 `base-sdk` 需要提供与检测业务、数据库实现解耦的表达式能力。

## 需求

- 在 `baseSdk.rule.spel` 提供通用 SpEL 规则定义、编译和执行能力。
- 规则在快照切换前统一编译，避免请求执行阶段重复解析表达式。
- 支持规则优先级、启停状态和通用扩展属性。
- 支持首条命中和全部命中两种执行模式。
- 支持失败即停和跳过错误两种异常策略，并返回逐条错误信息。
- 编译后的规则集必须不可变、线程安全，可直接作为热加载模块的快照类型。
- 禁止 Bean 引用、类型引用、构造器、函数调用、实例方法调用和赋值等高风险 SpEL 能力。
- 限制单个规则集数量和表达式长度，异常描述统一使用英文。
- 第一版不接入具体业务规则、数据库表或管理台接口。
