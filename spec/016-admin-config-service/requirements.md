# 016 需求

新增独立管理台服务，允许管理员查看、创建、修改和停用数据库中的服务配置项，并支持中文与英文接口响应。保持现有检测服务与数据 SDK 的模块边界。

## 验收标准

- 管理台独立启动、独立端口，不加载检测业务与 MQ 组件。
- 配置项可按命名空间列出、按键查询、创建、修改及停用；查询应包括已停用项。
- 写操作携带客户端期望版本；版本冲突返回 409，不能静默覆盖。
- 所有管理台请求必须认证，未配置管理员凭证时不能启动。
- 成功与错误消息依据 `Accept-Language` 使用简体中文或英文，错误码保持稳定。
- 写操作有不包含配置值的审计日志；数据库 SQL 仍集中在 Mapper XML。
