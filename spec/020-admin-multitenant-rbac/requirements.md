# 020 需求：管理台多租户 RBAC

## 目标

- 管理台采用“用户 -> 角色 -> 权限集合”的 RBAC 模型。
- 用户必须在指定租户下登录，访问令牌不得保存明文。
- 配置、规则集、规则草稿和规则发布记录必须按 `tenant_id` 隔离。
- 禁用用户、撤销令牌或调整角色后，权限变更应立即生效。
- 保持管理台中英文错误响应和既有乐观锁语义。

## 验收标准

- 未认证请求返回 `401`，缺少接口权限返回 `403`。
- 相同业务编码可在不同租户中独立存在。
- 任意业务查询、更新、发布和热加载 SQL 都包含租户条件。
- 支持登录、退出、查询当前身份、创建用户、查询角色及分配角色。
- 初始管理员密码只从环境变量读取并使用 BCrypt 保存。
