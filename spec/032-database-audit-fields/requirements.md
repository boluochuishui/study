# 需求 032：现有业务表统一审计字段

## 验收要求

- 为 `content_risk` 的现有 12 张业务表统一补齐 `created_by`、`created_at`、`updated_by`、`updated_at`。
- 操作人保存用户 ID；`0` 表示系统执行或历史操作人无法追溯，不为操作人字段建立用户外键。
- 用户新增/修改数据时由服务端身份填充操作人，客户端不能指定。
- 更新时保留创建人和创建时间，刷新更新人和更新时间；关系表也记录创建信息。
- 不修改 V1 到 V7，新增 V8 SQL 迁移，保留原数据和已有时间。
- 发布快照、在线测试记录创建时四字段完整，继续保持现有追加写入方式。
- 不修改第三方管理的 `flyway_schema_history`。
