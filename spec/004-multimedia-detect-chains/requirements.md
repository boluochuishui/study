# 需求说明

## 背景

统一检测接口已经具备 `contentType` 字段，责任链运行时也已经支持通过 `*.chain.properties` 组装固定链路。本需求需要基于责任链生成文本、图片、音频、视频四类内容检测流程。

## 目标

- 根据 `contentType` 路由到不同检测链。
- 文本链执行参数校验、关键词、正则、文本模型。
- 图片链执行参数校验、图片下载、OCR、文本风险、图片模型。
- 音频链执行参数校验、音频拉取、ASR、文本风险、文本模型。
- 视频链执行参数校验、视频拉取、抽帧、文本风险、文本模型。
- 每条链都配置统一 finally 节点。

## 非目标

- 本阶段不接真实 OCR、ASR、CV、NLP 模型。
- 本阶段不做异步视频任务。
- 本阶段不实现管理台规则配置。

## 验收标准

- [ ] 四条链可以在启动时被加载。
- [ ] TEXT 请求执行 `text.detect.chain`。
- [ ] IMAGE 请求执行 `image.detect.chain`。
- [ ] AUDIO 请求执行 `audio.detect.chain`。
- [ ] VIDEO 请求执行 `video.detect.chain`。
- [ ] 风险内容可以返回 `REJECT`。
- [ ] 正常内容可以返回 `PASS`。
